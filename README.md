# Infinite Dimensions

Infinite Dimensions is a Fabric mod for Minecraft 1.21.1. It adds portal-related gameplay, including custom portal tools/blocks and runtime-managed dimensions used by the mod systems.

## Requirements

- Minecraft: 1.21.1
- Java: 21+
- Fabric Loader: 0.17.3+
- Fabric API: 0.116.7+1.21.1

Versions come from `gradle.properties` and `fabric.mod.json`.

## Build

```bash
./gradlew build
```

The built JAR is generated under `build/libs/`.

## Run (development client)

```bash
./gradlew runClient
```

## Project

- Mod ID: `infdimmod`
- Maven group: `com.infdimmod`
